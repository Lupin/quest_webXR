📦 Volume XR v0.4.0

Volumes à l’échelle réelle dans ton Quest 3.

Dans le casque : « Start AR », vise le sol avec un contrôleur et appuie sur la gâchette. Gâchette INDEX : viser et saisir une caisse pour la déplacer, relâcher pour la poser ; viser le vide et appuyer pour créer une caisse. GRIP : maintenir pour tourner la caisse sélectionnée avec la manette. Stick horizontal : rotation fine. Caler sol : poser le contrôleur au sol, puis appuyer sur « Caler sol » ou le bouton A/X. Le sol n’est pas détecté automatiquement.
